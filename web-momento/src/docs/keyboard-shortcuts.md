# Keyboard Shortcuts

## Command palette

| shortcut | action |
| --- | --- |
| `⌘K` / `Ctrl+K` | Toggle the command palette from anywhere |

The palette searches every navigation destination (all groups), quick actions (Command Center, Downloads, Documentation, Ingest), and the documentation index. Type to filter, Enter to jump, Esc to dismiss.

## Navigation

- The **sidebar** carries the full sitemap, grouped: Operations, Intelligence, Execution, Data & Platform, Research, Administration, Consumer App. On screens below `lg` it slides in as an overlay from the top bar's menu button.
- **Top bar search** opens the same palette; the connection pill shows live backend health (`core 5.0.0 · N rounds`) with a status dot.
- Operator-only pages (Master Settings, Users, Round Testing) are hidden for non-operators and enforced server-side.

## Live mode

- **Go live** (Command Center) starts the provably-fair engine and switches all open views to 4-second refreshes.
- **Step round** generates one round on demand — handy while verifying forecasts in Forecast Studio or Pro Predictions.

## Tips

- The downloads button in the top bar always serves the latest registered release.
- Every page URL is deep-linkable; the sitemap from both previous archives routes 1:1 (aliases like `/dashboard/crash-studio` → `/dashboard/studio` included).
